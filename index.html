制作実績

自主制作1. LP「ETERNAL PET」

LP制作（デザイン／コーディング）｜ 公開中：eternal-pet-concept.netlify.app

ペットの長寿ケアという未来の会員制サービスを想定したコンセプトLP。「医療のように精密で、家族のように温かい」という世界観を、青を基調としたクリーンなデザインと大きなタイポグラフィで表現しました。デザインシステム（色・書体・コンポーネント）を先に設計し、全セクションのトーンを統一。日英2言語・レスポンシブ対応。

担当範囲：コンセプト設計／デザイン／コーディング（全て）　制作期間：約2時間（AI活用ワークフローによる短納期制作の実例）　使用ツール：Figma、HTML/CSS、JavaScript

実案件2. 企業公式サイト「SUNLADY FASHION DIRECT」

Webサイト制作（デザイン／実装／運用）｜ Next.js / microCMS ｜ 公開中：sunlady.tokyo

アパレル企業の公式サイト。ブランドの世界観を保ちながら、取引先や採用候補者が必要な情報へ迷わず辿り着ける構成に設計しました。色・余白・タイポグラフィを定めたデザインの設計書を整備し、ニュース更新はCMS化して運用負荷を軽減。アニメーションを含むレスポンシブ実装まで一貫対応しています。

担当範囲：デザイン／実装／運用　状態：公開中・運用継続中　使用ツール：Figma、Next.js、microCMS

自主制作3. 家族見守りサービス「MimamoriVoice」

サービスUIデザイン／開発 ｜ Next.js / LINE連携 ｜ 稼働中：mimamori-voice.vercel.app

離れて暮らす家族が声を届け合う見守りサービス。「見守られている感」ではなく「声が届く温かさ」を軸にコンセプトを設計し、音声一覧やカレンダーなど日常的に使う画面の情報設計から実装まで担当しました。

担当範囲：コンセプト設計／UIデザイン／実装（全て）　使用ツール：Figma、Next.js、LINE Messaging API

自主制作4. LINEリッチメニュー（デザイン学習Bot）

LINEリッチメニュー デザイン／実装 ｜ LINE Messaging API

デザインの名作を毎日届ける学習Botのリッチメニュー。2ボタン構成で視認性とタップしやすさを両立させ、昼（新作）と夜（名作）で色調を分けて時間帯の感覚も表現しました。Flex Messageの学習カードUIも設計しています。

担当範囲：デザイン／実装（全て）　使用ツール：Illustrator、LINE Messaging API
